# Medical-ChatBot-
A Flask-based AI Medical Chatbot powered by OpenAI GPT-4o-mini. Features include contextual conversations, SQLite-based chat history, multiple chat sessions, and the ability to view and delete previous conversations. Built using Python, Flask, HTML, CSS, JavaScript, and SQLite for learning AI integration and full-stack development.
